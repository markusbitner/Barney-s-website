Bike Auxiliary System

A compact embedded system powering bike lights and a buzzer from a rechargeable Li-ion battery.

Overview

This system powers a buzzer, headlight, and tail light using a rechargeable Li-ion battery. The buzzer acts as an electronic bell, while lighting is controlled via a single switch.

  • Minimize PCB size
  • Reduce redesign cycles due to hardware issues

Buzzer Sub-system

Problem: Standard bike bell is difficult to use with gloves in winter.
Solution: Electronic buzzer activated by button input.

Buzzer used: AI-3035-TWT-3V-R

  • ~3500 Hz resonance, similar to bike bell tone
  • 100 dB at 10 cm sound pressure level
  • Through-hole component for easier prototyping

Frequency generation uses LTC6990, tuned to ~4 kHz (div code = 7).

Simulation and design workflow: LTspice simulation → frequency validation → Altium schematic → PCB layout.
