Payload Electronics — STARR Rocketry

Designing signal integrity systems for payload control, including buffering, connectors, and noise mitigation for motors, servos, and data buses.

Overview

The payload motherboard collects sensor data and controls servos and motors during descent. Because signals degrade due to distance and vibration, buffering and signal conditioning are critical.

Buffer Board

Problem: Noisy PWM signals from the payload motherboard caused unstable servo and motor behavior.

Solution: A dedicated buffer board using NC7WZ16 to clean and stabilize control signals.

My Role

  • Schematic design in Altium Designer
  • Component selection
  • PCB layout optimized for signal integrity and manufacturability
  • Iterative redesign aligned with power distribution updates

Design Considerations

  • Proper chip power delivery
  • Routing power for servos and motors through the board
  • Ensuring clean output: GND, filtered signal, and power lines

Connector Board

Problem: Data buses became noisy, affecting communication reliability with the motherboard.

Solution: Designed a connector and buffer board using SN74LVC126A for SPI buffering and TCA4307 for I2C hot-swapping and signal conditioning.

My Role

  • Schematic design in Altium Designer
  • Component selection and system integration
  • PCB layout with focus on compactness and signal integrity

Design Considerations

  • Stable chip power distribution
  • Clean routing for high-speed data buses
  • Easy integration with existing payload architecture
